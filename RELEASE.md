# v0.27.4 - In-universe timeline and compressed release assets

**2026-11-05**

## What's Changed

Everything since v0.27.3:

- **In-universe timeline on rows.** `transcripts`, `interactions`, `items`,
  `records`, `books`, `grimoire_cards` and `character_lines` carry `timeline`
  (story-chapter slug from the new rank-ordered `timeline_chapters`
  vocabulary, Pre-History through Renegades, 23 chapters) plus
  `timeline_basis` (`classification` | `release_name` | `scene_flashback` |
  `ishtar_timeline`; NULL means unknown). Dialogue follows the when-spoken
  rule: an explicitly past-set scene beats its release position.
- **Ishtar timeline snapshot.** `source/ishtar-timeline.json` (45 eras, 800
  source links) is generated by `scripts/ishtar-timeline.py` and consumed
  offline by the build: curated event time for books (31/110), records
  (70/71), extra items and the 110 on-timeline cards. `--report` diffs
  Ishtar's about-time against the when-spoken chapters: 442/1312
  transcripts carry Ishtar tags, 22 disagreements listed for curated review
  (no bulk apply). `fts.timeline` makes chapters searchable and filterable
  through `search(timeline=...)` in the API, MCP and CLI.
- **Compressed release assets.** `.github/workflows/release-assets.yml`
  publishes `grimoire.db.xz` (29 MiB, xz -9e) and `grimoire.db.gz` (56 MiB,
  gzip -9, byte-reproducible) with a refreshed `SHA256SUMS` on every
  release, plus a daily sweep that verifies both compressed assets
  decompress byte-identical to the published database and repairs them when
  stale. Static endpoints: `/releases/latest/download/grimoire.db.xz` and
  `.gz`; the gzip asset is the zero-dependency pick for Android apps
  (`GZIPInputStream`).
- **Agent-optimization pass** (search stage-direction demotion and
  `exclude_stage`, 25-token snippets, one-call item lookups with lore
  links, anchored `spoken_lines`, expanded MCP instructions, 16K resource
  caps, skill description trimmed to 150 bytes, peer source-repo permission
  denies, three new gates: MCP agent-optimization 25, permission-leak 240,
  count-consistency).
- **CI rebuilt around local-only enrichment dumps:** gates test the
  verified release asset (like the agent repos) with a migrate-only smoke
  build from tracked sources; both CodeQL URL-substring alerts fixed.
